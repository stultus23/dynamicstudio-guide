## 操作步骤（关键操作）

### 查看可用附加项
- **说明**：DynamicStudio Base Package 包含核心功能
- **附加项**：
  - 2D PIV（平面 PIV）
  - Stereoscopic PIV（立体 PIV）
  - Optical Flow/Motion Tracking（光流/运动跟踪）
  - Flex Grid & Flex PIV（灵活网格 PIV）

### 激活附加项
- **步骤**：
  1. 获取 USB 加密狗
  2. 插入加密狗
  3. 重启 DynamicStudio
  4. 验证附加项可用
