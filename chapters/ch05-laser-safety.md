# Chapter 5: Laser Safety（激光安全）

> 完整原文：`raw/ch05.txt`（35 行）· 各小节均标注打印页码，可据此在原文中定位。

## 核心概念

所有使用激光的设备必须标注安全信息。Dantec 系统采用 Class III 与 Class IV 级激光，光束具有危险性，操作前务必阅读激光与光学器件文档中的安全章节，采取适当的激光安全措施并遵守当地法规，激光运行时须佩戴防护眼镜。在光路对准与使用照明系统时必须落实安全措施：作为通用防护，应仔细遮挡反射光，防止其逸出测量区域，避免对眼睛造成伤害。

## 操作步骤（关键操作）

### 激光安全检查
- **步骤**：
  1. 佩戴激光护目镜
  2. 检查激光安全标签
  3. 屏蔽反射光
  4. 对齐时低功率运行
- **说明**：Class III/IV 激光有安全风险

### 相机传感器保护
- **步骤**：
  1. 不使用时盖上镜头盖
  2. 对齐光片时盖上镜头盖
  3. 移除镜头盖前检查反射
- **说明**：直射/反射激光会永久损坏传感器
