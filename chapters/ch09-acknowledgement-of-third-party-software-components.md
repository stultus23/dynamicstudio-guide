# Chapter 9: Acknowledgement of Third Party Software Components（第三方软件组件致谢）

> 完整原文：`raw/ch09.txt`（699 行）· 各小节均标注打印页码，可据此在原文中定位。

## 核心概念

DynamicStudio 使用了以下第三方软件组件（各组件许可条款详见本章后续章节）：Intel IPP 与 MKL、OpenCV、马里兰大学 ANN（Sunil Arya 与 David Mount）、Boost C++ 库、NVIDIA CUDA Toolkit、Ingo Berg 的 muParser、Tiflib、VTK、Math.net Numerics、OpenFOAM。

## 操作步骤（关键操作）

### 查看第三方组件
- **UI 路径**：Help → About → Third Party Components
- **组件列表**：
  - IPP and MKL from Intel
  - OpenCV
  - ANN (University of Maryland)
  - Boost C++ libraries
  - NVIDIA CUDA Toolkit
  - muParser from Ingo Berg
  - Tiflib
  - VTK
  - Math.net Numerics
  - OpenFOAM

### 了解第三方许可
- **说明**：每个组件都有自己的许可协议
