# Chapter 8: Software Update Agreement（软件更新协议）

> 完整原文：`raw/ch08.txt`（7 行）· 各小节均标注打印页码，可据此在原文中定位。

## 核心概念

Dantec 建议注册产品并签署软件更新协议（Software Update Agreement, SUA），以获得免费软件更新、手册与工具。更多信息参见软件注册（Software Registration）相关说明。

## 操作步骤（关键操作）

### 注册软件更新协议
- **说明**：注册后可获取免费软件更新、手册和工具
- **步骤**：
  1. 访问 Dantec Dynamics 网站
  2. 注册产品
  3. 签署 Software Update Agreement
  4. 获取更新访问权限

### 检查更新
- **UI 路径**：Help → Check for Updates
- **说明**：定期检查软件更新
