## 核心概念

You can get help on dialog by pressing the F1 button.

## 操作步骤（关键操作）

### 获取对话框帮助
- **快捷键**：F1
- **说明**：在任何对话框中按 F1 获取帮助

### 使用 Sort 对话框
- **UI 路径**：右键数据 → Sort
- **排序方式**：
  - Sort by Timestamp（按时间戳排序）
  - Sort by Data Column Value（按数据列值排序）
  - Sort by Property Value（按属性值排序）

### 使用 Split 对话框
- **UI 路径**：右键数据 → Split
- **分割方式**：
  - Split at Index（按索引分割）
  - Split at Sort Property Value（按排序属性值分割）
  - Automatic（自动分割）
  - Custom（自定义分割）

### 使用 Merge 对话框
- **UI 路径**：右键数据 → Merge
- **说明**：合并多个数据集
